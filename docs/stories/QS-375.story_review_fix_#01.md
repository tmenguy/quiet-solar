# QS-375 — review fix #01 (PR #411, round 1)

Reviewers on `c2a2125f`: blind-hunter, edge-case-hunter and
acceptance-auditor. CodeRabbit was rate-limited (free tier) and did not
review. No must-fix from anyone; the acceptance auditor found every AC and
decision implemented and tested, with two small gaps.

## Fix

1. **F1 (blind-hunter) — `FIXED` is unused.** The `overlaps_fix` query
   builds its state list from `FIXED`.
2. **F2 (blind-hunter) — `relates_to` reads any finding.** A related row
   outside the writer's run is `NOT_FOUND`, so no other run's rationale is
   copied into a flag (D13's scoping).
3. **F3 (edge-case-hunter) — a title that normalises to `""`.** `"???"` or
   `"—"` would strong-match every other such title. `norm(title) == ""` is
   `USAGE`.
4. **F4 (edge-case-hunter) — `file:line` and path spellings.** A `file`
   ending in `:<n>` or `:<n>-<m>` is `USAGE` (lines go in `line_start` /
   `line_end`); a backslash is `USAGE`; the path is normalised
   (`posixpath.normpath`), so `a//b`, `a/./b` and `a/b/` are one file.
5. **F5 (acceptance-auditor) — the `gate` half of the severity override**
   is tested.
6. **F6 (acceptance-auditor) — the JSON of `blast-radius set` and
   `ledger show`** is written in `control-plane.md`.
7. **F7 (all three, nice-to-have) — `--state ""` / `--state ","`** is
   `USAGE`, not "no filter".
8. **F8 (blind-hunter, edge-case-hunter) — `--cause` equal to the finding
   itself** is `USAGE`.
9. **F9 (edge-case-hunter) — blank strings.** `--head`, `--base`,
   `--commit`, `--reason`, `--note` and the item's `sha` / `reviewer` are
   stripped; empty becomes `None` (a required one is `USAGE`), so a reason
   of `""` is stored NULL (D6) and a `sha` of `" c1"` matches `c1`.
10. **F10 (edge-case-hunter) — export injection.** The rounds' shas and the
    blast radius's review and reason go through `export._cell`.
11. **F11 (edge-case-hunter) — `convergence` on an unknown task** is
    `NOT_FOUND`, never a clean-looking answer.
12. **F12 (edge-case-hunter) — bad `--input`.** A non-UTF-8 file and JSON
    nested past the recursion limit are `USAGE`, not `INTERNAL`.
13. **F13 (edge-case-hunter) — integers above SQLite's range** (item ints,
    the ID positional, `--cause`, `--round`) are `USAGE`, not `INTERNAL`.
14. **F14 (blind-hunter, edge-case-hunter) — the U+001F separator** is
    refused in `title`, `file`, `symbol`, `reviewer` and `sha`, so no two
    key fields can shift into each other.
15. **F15 (edge-case-hunter) — Unicode spellings.** `norm` applies NFKC and
    `casefold`, so `Café` typed precomposed or decomposed is one title.
16. **F16 (blind-hunter, edge-case-hunter) — `show`'s queries.** The flagged
    rows' states come in one query, and the events by a sub-select, not one
    bind parameter per id.
17. **F17 (blind-hunter) — the export's phase order** is explicit (`plan`,
    then `build`), not alphabetical.
18. **F18 (edge-case-hunter, doc only) — a `round start` retry.** The
    contract says a node that lost `round start`'s answer reads `ledger
    show` before calling it again (D3 keeps every call a new round).
19. **F19 (acceptance-auditor, nice-to-have)** — the two-call
    "separate row and `matches` flag" case is asserted explicitly, and the
    `relates_to` de-duplication is written in the item table.

## Rejected

- **`rounds` / `blast_radius` of a task with no run in `snapshot --run`**
  (blind-hunter): §4 fixes the filter (`task_id IN` the run's tasks); these
  tables have no `run_id`, and the findings rule exists only because a
  finding records its writer's run.
- **Register the export outside `cli`** (blind-hunter): §3 decides that the
  export is reachable only through `cli` (`export-summary`, and child 7's
  merge tool runs in the CLI process).
- **A same-state `finding state` that changes `--reason` / `--commit`**
  (blind-hunter): D6 makes it a noop on purpose; a changed rationale is a
  reopen and a new settle, two honest events.
- **`round start` idempotency** (edge-case-hunter): out of scope (D3, "an
  idempotency key on `round start`"); F18 documents the retry.
- **A NULL base after a plan round with no head** (edge-case-hunter): D4's
  default is the previous round's head, NULL included; plan rounds carry no
  diff.
- **Refuse round 0 for reviewer sources** (edge-case-hunter): the contract
  hands the reviewer `--round`; round 0 stays the default for corrections
  before any round (D16).
- **Drop `ON CONFLICT … DO NOTHING`** (blind-hunter): D10 asks for it as the
  insert's guard; it costs nothing.
- **`USAGE` on a non-`must_fix` ci / gate severity** (blind-hunter): §2
  overrides it by design.
- **A birth event for a born-closed row** (blind-hunter): §1, a finding's
  opening is its row.
- **`export._cell` made public, `flags` decoded per table**
  (blind-hunter): the helper is inside the package, and no other table has
  a `flags` column.
