# QS-375 — review fix #03 (PR #411, round 3 — convergence)

Reviewers on `8294e67d`: the acceptance auditor converged (every G-item
implemented and tested, the Control Plane at 100% over its whole suite, no
AC, decision or F-item broken). The blind and edge-case hunters found no
must-fix, and one shared should-fix that G4 introduced.

## Fix

1. **H1 (blind-hunter, edge-case-hunter) — a blank `head_sha` reads another
   head's rating.** G4 stripped the reader's `head_sha` to `None`, which
   means "any head", so a merge gate passing an empty sha would get a stale
   rating. A given-but-blank `head_sha` now returns `None` (no rating);
   only an omitted one means "the latest of any head".
2. **H2 (edge-case-hunter) — `a.py:42 /`.** The `:<line>` suffix check
   runs on the normalised path with its trailing whitespace stripped.
3. **H3 (blind-hunter, edge-case-hunter, acceptance-auditor) — a lone
   surrogate in a CLI flag** (`--reason $'\xff'` under POSIX
   `surrogateescape`) is `USAGE` for the ledger's commands: `_text` checks
   it, as `_opt` does for the items.
4. **H4 (blind-hunter) — `reviewer` is NFC,** like `file` and `symbol`, so
   one lens spelled two ways replays.
5. **H5 (blind-hunter) — backticks in the blast-radius review and reason**
   are dropped too, so none opens a stray code span in the summary.

## Rejected

- **Read stdin as raw bytes and decode UTF-8 explicitly** (blind-hunter):
  every Control Plane command (hooks included) reads `io.stdin` as text, and
  the tests inject a `StringIO`; a locale-independent stdin is a CP-wide
  change, not this child's.
- **A CP-wide `UnicodeEncodeError` → `USAGE` in `cli.main`**
  (acceptance-auditor, optional): outside #375's scope; H3 covers the
  ledger's own flags.

## Round 4 (on `e25cdc05`) — fix #04

The edge-case hunter and the acceptance auditor converged on fix #03; the
blind hunter found H2 incomplete, and the edge-case hunter a neighbouring
nice-to-have:

6. **I1 (blind-hunter, edge-case-hunter) — whitespace-padded segments.**
   `a.py:42 / /` or `a.py:42 /. /` still carried the line past the check,
   and `a.py /` was stored as `a.py ` (another fingerprint). `norm_path`
   strips **each segment** before `normpath`, so both fold to `a.py:42`
   (refused) and `a.py`.
7. **I2 (acceptance-auditor, doc)** — the item table says `reviewer` is
   trimmed and NFC (it is part of the replay key).

## Round 5 (on `73cab91e`) — converged

The blind and edge-case hunters found no must-fix and no should-fix in fix
#04 (the acceptance auditor had converged on round 4). Rejected, both
optional and older than #04:

- **Zero-width characters (U+200B, U+FEFF, …) in a path** (edge-case
  hunter): `str.strip()` keeps them; a pasted path carrying one is a rare
  artefact, and refusing or folding every invisible code point is polish
  beyond the fingerprint's purpose.
- **A non-blank path that reduces to `.`** (edge-case hunter): it is "no
  file", consistent with the documented "empty is absent"; the fingerprint
  then falls back to the title, which is the D8 rule for a finding with no
  file and no symbol.
