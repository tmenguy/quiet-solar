## Findings to fix

### [should-fix] S1 — `render_all` default for a missing `model` key bypasses the policy
- File: `scripts/qs/render_agents.py:374`
- Severity: should-fix
- Source: qs-review-edge-case-hunter (dup: qs-review-blind-hunter)
- Description: `model_spec = context.get("model", "inherit")` falls back to
  `"inherit"` when a hand-built/partial context omits `"model"`, while
  `build_render_context` now defaults `model=None` — the only value that
  selects the policy path (model + effort). A caller omitting the key
  silently renders every agent with `model: inherit` and no `effort:`.
- Proposed fix: `model_spec = context.get("model")` so a missing key
  applies the policy exactly like `build_render_context`'s default. TDD:
  add a test that renders with a context dict lacking `"model"` and
  asserts the policy model/effort land (e.g. `qs-finish-task` has no
  `effort:` and a policy model; a deep agent has `effort:`), and never
  `model: inherit`. Check existing tests that relied on the old
  `"inherit"` fallback and pass `model="inherit"` explicitly where they
  meant it.

### [nice-to-have] N5 — `ModelPolicyError` escapes `next_step` as a traceback
- Files: `scripts/qs/launchers/claude.py:529`, `scripts/qs/next_step.py:253-277`
- Severity: nice-to-have
- Source: qs-review-edge-case-hunter
- Description: `build_payload` calls `models.resolve(lane, agent)`; a
  phase agent without a policy row raises `ModelPolicyError`
  (a `ValueError`), which `next_step.main` doesn't catch (only
  `UnknownPhaseError`) → raw traceback instead of a JSON error payload.
  Unreachable today (`test_phase_agents_have_policy_rows`), defense in
  depth only.
- Proposed fix: in `next_step.main`, add a separate
  `except models.ModelPolicyError as exc:` branch (do NOT broaden the
  `UnknownPhaseError` branch — review-fix #02 SF1 rule) emitting
  `{"error": "no model policy row", "value": <agent>, "detail": str(exc)}`
  and `sys.exit(1)`. TDD: a test that monkeypatches the launcher's
  `models.resolve` (or the phase map) to raise `ModelPolicyError` and
  asserts JSON error on stdout + exit 1. Keep 100% changed-line coverage.
