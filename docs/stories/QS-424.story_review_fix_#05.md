## Findings to fix

### [must-fix] J1 — raw HTML in a value hides, nests or restyles every later section
- File: `scripts/qs/control_plane/export.py`
- Source: edge-case-hunter
- Description: `why = "<!-- todo"` — GitHub's output stops at `### Why`: every later digest block and every summary section is gone. Same for `<?x`, `<![CDATA[`, `<table>` (later sections nested), unclosed `<b>`/`<s>`/`<code>`. The pipeline's own markers are HTML comments, so a cut-off one is a realistic value.
- Proposed fix: on every value line, a `<` that opens a tag, a comment, `<?` or `<!` (not a URI autolink) becomes `&lt;` (an HTML block ignores backslash escapes). Cosmetic in code (`List&lt;int>`). Tests.

### [must-fix] J2 — a setext underline under a `    >` line
- File: `scripts/qs/control_plane/export.py`
- Source: blind-hunter, edge-case-hunter
- Description: `"foo\n    >\n==="` renders `<h1>foo &gt;</h1>`: an indented `>` is paragraph text, not a blank quote line.
- Proposed fix: insert the blank line unless the previous output line is exactly empty; the five repro shapes as tests.

### [must-fix] J3 — link-reference definitions with a multi-line or escaped label
- File: `scripts/qs/control_plane/export.py` (`_DEFINITION_RE`)
- Source: blind-hunter, edge-case-hunter, acceptance-auditor
- Description: `"[foo\nbar]: https://evil.example"` and `"[a\\]b]: …"` stay live and redirect a `[foo bar]` anywhere in the summary; a label line ending in a lone `\` too.
- Proposed fix: escape a line-start `[` whose label closes with `]:` or does not close on the line, honouring backslash escapes (`(?:[^\]\\]|\\.?)*+`); tests, including `[x] done`, `- [ ] todo`, `[link](u)` left alone.

### [should-fix] J4 — a NUL in a digest value makes the summary a binary file
- File: `scripts/qs/control_plane/export.py`
- Source: edge-case-hunter
- Proposed fix: render a NUL as U+FFFD (what CommonMark does); test.

### [should-fix] J5 — `--round` is not checked
- File: `scripts/qs/control_plane/reports.py` (`post_report`)
- Source: edge-case-hunter
- Description: `--round -1` is stored; `--round 2**63` is INTERNAL (an SQLite overflow inside the transaction).
- Proposed fix: `USAGE` unless `0 <= round <= SQL_INT_MAX`, before the transaction; tests.

### [nice-to-have] J6 — `questions` ids have no digit limit
- File: `scripts/qs/control_plane/reports.py`
- Source: edge-case-hunter
- Proposed fix: `Q-[1-9][0-9]{0,18}` and `<= SQL_INT_MAX`; tests.
