## Fix

| # | Source | Where | Fix |
|---|---|---|---|
| MF-1 | blind-hunter, edge-case (must-fix) | `integrate_item.py` `_scratch_git_broken` | Resolve a relative `gitdir:` back-pointer against the admin dir (git ≥ 2.48 `worktree.useRelativePaths`), and compare with `os.path.samefile`. Without this, a **healthy** relative-path scratch was classed `git_unreadable` and removed **without a snapshot**. Test: `worktree.useRelativePaths=true`, dirty scratch → snapshot kept. |
| SF-1 | edge-case | `_scratch_git_broken` | An `OSError` reading `.git` or `<admin>/gitdir` is not proof of breakage. It returns `False` and git decides, giving `drop-failed` when nothing reads. Paths are read with `surrogateescape`. |
| SF-2 | edge-case | `integrate_item.py` `_emit` | Lone surrogates (non-UTF-8 path bytes) are emitted as `\xNN` text, because the Control Plane stores outputs in sqlite, which refuses them. Internally, raw names still work as pathspecs. |
| SF-3 | edge-case | `cmd_drop` / `_snapshot` | An orphan HEAD with dirty files: parentless snapshot (`read-tree --empty`) instead of a silent loss. |
| B-SF1 | blind-hunter | `cleanup_worktree.py` `_cas_delete_branch` | Also remove the `branch.<item>.*` config section, as `git branch -D` does. |
| B-SF2 | blind-hunter | `cmd_move` | `already-moved` after a race also reports `now` (the actual `QS_<N>` tip). |
| B-SF3 | blind-hunter | `_cas_delete_branch` | Neutral failure message ("moved, or ref locked"). |
| NF-3 | edge-case | tests | `QS_<N>` deleted right after the fast-forward → `move-failed`. |
| NF-5 | both | `cmd_drop` | Unreachable branch removed. |
