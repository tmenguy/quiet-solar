# QS-451 — Remove the second pipeline (QS-369) from quiet-solar; unfreeze today's pipeline

- Issue: #451 · Lane: feature × factory · Branch: `QS_451`
- Status: implemented

## Why

Epic #369 pivoted on 2026-10-31: the second pipeline (orchestrators over a
task tree, on a Control Plane) is rebuilt as a reusable harness in its own
repository, [tmenguy/SPHarness](https://github.com/tmenguy/SPHarness),
which already carries the Control Plane, its tests, the node and review
agents and the epic's history. What it added to quiet-solar is dead
weight, and today's pipeline (the lanes, `setup-task` → `create-plan` →
`implement(-setup)-task` → `review-task` → `finish-task`, `release`) is no
longer frozen: the maintainer keeps evolving it.

## What was kept

They improve today's pipeline:

- #371 — `--impacted` runs the CI-mirrored cheap checks;
- #372 — the handoff plumbing and lane routing;
- #398 — `get_issue_from_branch` accepts only `QS_<digits>`;
- #404 — `epic_doc.py land` carries an epic's rendered SVGs, and
  `--impacted` fails on a stale SVG;
- #417 — the Mermaid diagram of the pipeline in `overview.md`;
- the model policy's later edits: `build` on Opus 5.5 (2026-10-04) and the
  `fast` class on `claude-haiku-5-5` (2026-10-09, Haiku 4.5 is deprecated).

`tests/qs/test_worktree_setup.py` and its `tests/qs/_gitrepo.py` fixture
(born with #400) are kept, trimmed to the `QS_<N>` task path: a real-git
regression test of the path today's pipeline uses.
