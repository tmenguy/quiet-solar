### [should-fix] R5-1 — a persisted pre-selection (never attached) is lifted by the boot guard

- Description: the save stamps `STORAGE_KEY_USER_PIN_SAVED_AT` / `_PLUG_STATE` for every real pin, including a pre-selection on an unplugged charger whose car was never attached here. Do NOT discriminate on `_boot_car` (it is set for a pre-selection too). Do NOT add the optional "re-save original saved_at while armed" (maintainer rejected boot-slot rewrites in round 1). Tests: the reviewer's repro inverted (pre-selection across restart + car unplugged elsewhere → pin kept); a save-time row (pin on a non-attached car → both keys `None`); existing attached-pin guard tests still green. Fix the story dev note (~l.573) and the `user-override.md` wording.
