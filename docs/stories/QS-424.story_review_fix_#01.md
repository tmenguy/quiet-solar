## Findings to fix

### [should-fix] F1 — the digest export's Markdown rendering is not structure-safe
- File: `scripts/qs/control_plane/export.py:24-41`
- Source: blind-hunter, edge-case-hunter (1, 2, 3, 4, 7)
- Description: `_demote` prefixes `###` to any line starting with `#`: a `#424 merged` or `#tag` line becomes `####424 merged`; a `# comment` inside a fenced code block is corrupted; an h4–h6 heading becomes 7–9 `#` (no longer a heading); a setext heading (`Decisions` over `---`) still adds a level-2 "Decisions"; an unclosed fence in one value swallows the rest of the summary.
- Proposed fix: one line scanner per value: demote only a real ATX heading (`#{1,6}` then a space, a tab or the end, after at most three spaces), capped at level 6; leave every line inside a ```` ``` ```` / `~~~` fence alone (CommonMark closing rule: same character, at least as long); insert a blank line before a setext underline that follows a text line (`---` becomes a thematic break, `===` plain text); close a fence still open at the value's end. Tests for each case.

### [should-fix] F2 — a lone surrogate is INTERNAL, not USAGE
- File: `scripts/qs/control_plane/reports.py` (`validate_fields`, `put_digest` size checks)
- Source: edge-case-hunter (5)
- Description: `json.loads` accepts `"\ud800"`; `.encode()` then raises `UnicodeEncodeError`, answered `INTERNAL`.
- Proposed fix: the canonical size is computed by one helper that turns a `UnicodeEncodeError` into `USAGE` ("not valid UTF-8 text"); tests for a digest value and a `discovered` title.

### [should-fix] F3 — a prompt or message starting with `-` is read as an option
- File: `scripts/qs/control_plane/tools.py` (`_spawn_steps.launch`, `_resume_steps.launch`)
- Source: edge-case-hunter (6)
- Description: since D2 the prompt is the argv's last positional; `claude`'s parser reads a leading `-` (YAML front matter `---`, a list item) as an option, so the launch fails or a flag is taken. Same for `tool resume`'s message.
- Proposed fix: refuse it in `launch`, before `_launch` writes `launch_at` (`StepFailed`, like a model-policy refusal: nothing launched); tests for both tools.
