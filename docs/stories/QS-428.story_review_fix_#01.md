## Findings to fix

### [must-fix] The stale banner is never visible
- File: `scripts/qs/control_plane/board_render.py` (`SCRIPT`, `tick()`; the `stale-banner` div in `render()`)
- Severity: must-fix
- Source: qs-review-blind-hunter, qs-review-edge-case-hunter
- Description: `tick()` unhides the banner and then reloads at once (when nothing is
  selected); the reloaded page starts with the banner `hidden` and checks its age only
  on the next tick 10 s later. A stale page only flashes the banner — the one signal
  that the daemon stopped.
- Proposed fix: factor a `checkStale()` and call it once at script load, before the
  first `setTimeout`, and from `tick()`. While the page is stale, keep reloading (so a
  restarted daemon is picked up) — the banner now shows right after each reload. Keep
  `scrub(SCRIPT) == SCRIPT` and the CSP hash tests green; add a test pinning that the
  script calls the age check at load (a string assertion on `SCRIPT`'s structure is fine).

### [should-fix] `_halt` ignores the current code version
- File: `scripts/qs/control_plane/board.py:101-117` (`_halt`), `model()`, `render_to()`
- Severity: should-fix
- Source: qs-review-edge-case-hunter, qs-review-blind-hunter
- Description: `mergegate.merge_allowed` only halts on a failed record for the
  *current* version (`failed_record(conn, version)`), its override check uses the
  current version, and the pending mark counts only when its `code_version` is current.
  `_halt` flags any old failed record and masks only with an override for the record's
  version, so after a fix lands (V1 failed, main now V2) the board says "halted:
  failed" and its copy block tells the user to `halt clear` — which overrides V2
  before V2's self-check ran.
- Proposed fix: give `model()` / `_halt` the current code version (keyword
  `code_version: str | None`). `render_to` computes it with
  `codever.code_version(main)` — guarded: any exception → `None`. Mirror
  `merge_allowed`: no halt when the override's `code_version == current`; "failed"
  only when the record's `code_version == current`; "stuck" only for a pending mark
  whose `code_version == current`. When `current is None` (unknown), keep today's
  behaviour. Update D5 in the story and the control-plane.md Board section to match.
  Tests: old-version failed record → no halt; override for current version masks a
  record of the current version; pending of an old version → not stuck; unknown
  version → today's behaviour.

### [should-fix] `SHORT_ID` accepts a leading `-` (option injection in `claude attach`)
- File: `scripts/qs/control_plane/board_render.py` (`SHORT_ID`)
- Severity: should-fix
- Source: qs-review-blind-hunter, qs-review-edge-case-hunter
- Description: `--dangerously-skip-permissions` matches `[0-9a-zA-Z-]{1,64}` and
  `shlex.quote` leaves it bare, so the copy block becomes a flag.
- Proposed fix: `re.compile(r"[0-9a-zA-Z][0-9a-zA-Z-]{0,63}")` (fullmatch). Test: a
  `short_id` of `-x` / `--foo` gives no attach block.

### [should-fix] A lone surrogate from the DB makes every render raise
- File: `scripts/qs/control_plane/board.py` (`write`, `html.encode("utf-8")`)
- Severity: should-fix
- Source: qs-review-edge-case-hunter
- Description: `json.loads('"\\udc80"')` yields a lone surrogate (e.g. a backup error
  holding a surrogateescape'd path); strict UTF-8 encoding raises `UnicodeEncodeError`
  (a `ValueError`, not caught by the hook) — the board is never rewritten again and
  `cp.py board` returns `INTERNAL`.
- Proposed fix: `html.encode("utf-8", "backslashreplace")`. Test: a model value
  holding `"\udc80"` renders and writes.

### [should-fix] Cross-run alert groups take the first alert's fields only
- File: `scripts/qs/control_plane/board.py` (`model()`, `groups.setdefault(fp, {**_alert_row(a), "runs": []})`)
- Severity: should-fix
- Source: qs-review-blind-hunter
- Description: a group mixing cleared and open alerts shows the first one's
  `cleared`/`first_seen`/`last_seen`; a run with several alerts under one fingerprint
  is listed several times.
- Proposed fix: the group is open if any member is open; `first_seen` = min,
  `last_seen` = max (tolerant of `None`/unparseable values); `runs` de-duplicated in
  first-seen order. Test with a mixed group and a repeated run.
