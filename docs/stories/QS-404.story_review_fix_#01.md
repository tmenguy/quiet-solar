# QS-404 — review fix #01 (PR #409, round 1)

Reviewers: blind-hunter, edge-case-hunter, acceptance-auditor, CodeRabbit
(unavailable — stuck processing, no findings). Acceptance-auditor: every AC
1–22 implemented and tested.

## Fix

1. **F1 (must-fix) — `_impacted_diagram_check` import crash.** Move
   `import mermaid_svg` after the SKIP branch and inside the `try`, so a broken
   worktree renderer is a `[diagrams] error:` + `FAIL` line, never a traceback,
   and a run without `docs/` Markdown never imports it. Test: import made to
   fail (`sys.modules["mermaid_svg"] = None`) → error line; SKIP path untouched.
2. **F2 — SVG-only landed state never renders.** Before the D5 step-6
   non-SVG shortcut, take the shortcut when **every** changed path (SVGs
   included) already equals `main`. Test: only main's re-rendered SVG copied
   locally, main's renderer broken → `already-landed`, renderer never loaded.
3. **F3 — `SystemExit` from main's renderer.** `_declared_svgs` maps it to
   `diagram-error`. Test: seeded renderer `sys.exit(3)` → `diagram-error`, no
   leftover `sys.modules` key.
4. **F4 — pin `origin/main` once per land.** `cmd_land` resolves
   `origin/main^{commit}` right after the fetch and threads the sha through the
   merge-base, `_main_blob`, `_landed_doc_text`, `_main_renderer`, the conflict
   probe and `_build_commit` (read-tree, tree compare, `commit-tree -p`). A
   concurrent fetch then makes the push a non-fast-forward (`push-rejected`,
   "main moved — re-run") instead of silently overwriting main's change or
   landing SVGs drawn by a stale renderer. Test: origin/main moved (a doc edit
   on main + local fetch) while land renders → `push-rejected`, main's edit
   intact; the re-run → `conflict`.
5. **F5 — AST pin tightened.** Module-level assignment values may only call
   `re.compile`.
6. **F6 — case-insensitive duplicate `@out`.** `outputs_from_text` dedupes on
   the case-folded path (APFS). Test.
7. **F7 — hint for an already-deleted undeclared SVG.** Deleting an epic SVG
   is not supported (orphans are out of scope): the hint points to
   `git checkout origin/main -- <path>` only; a leftover keeps its
   "delete it, or restore" hint. Test asserts both.
8. **F8 — no conflict on a doc equal to main.** The conflict loop skips a path
   whose local blob equals main's. Test: main added the doc (declaring an SVG
   main lacks), local doc byte-identical + rendered SVG → `landed`.
9. **F9 — `fix:` line.** Shell-quote each path and compute every relpath
   against the resolved root.
10. **F10 — tests.** Guard `sys.path` in the gate test helper; assert no
    leftover renderer key on the two `out-of-scope` bad-hint tests.
11. **F11 — evidence.** Record the AC 21 gate runs in the PR body.

  through the same `_text_blob`, so the compared blob is the landed one; no
  defect.
- A comment on the hard-coded `100644` mode (blind): an SVG is never
  executable; no defect.
- Symlinked `docs/epics/img` (edge): unsupported layout; the refusal is safe.
- Shorter `fix:` line for the fail-closed `None` listing (blind): the line is
  accurate; a git failure is rare.
- "Doc deleted locally reaches `_read_doc`" (blind): invalid — step 5 refuses
  `missing-doc` first (`test_land_refuses_a_locally_deleted_doc`).
