### [should-fix] #2 — Reset button and disable toggle wipe constraints before `detach_car()` sees them
- File: `custom_components/quiet_solar/ha_model/charger.py:2900-2905` (`QSChargerGeneric.reset`)
- Severity: should-fix
- Source: qs-review-edge-case-hunter
- Description: two `reset()`-driven exits are neither unplug nor "no
  car": the charger **reset button** (`user_clean_and_reset` →
  `AbstractLoad.user_clean_and_reset` → `reset()`, `load.py:455-464`) and
  the **disable toggle** (`qs_enable_device = False` → `reset()`,
  `load.py:482`). Both go through `AbstractLoad.reset`, which wipes
  `_constraints` before `QSChargerGeneric.reset` reaches `detach_car`, so
  the round-5 in-`detach_car` clear is a guaranteed no-op there, and
  neither path has an explicit pre-reset clear (only `:3711` unplug and
  `:3772` "no car" do). Probe: step-1 leak (41 on car A) →
  `charger.qs_enable_device = False` → `charger.car is None`,
  `car._next_charge_target == 41`, `get_car_target_charge_option_percent() == "41%"`,
  zero clear-log lines; disabled devices leave the home loop, so the 41
  lingers for the entire disabled period. Reset button: 41 persists
  while detached; heals only if the car is re-attached before an
  unplugged read.
  **Why this is the closing move:** every exit either calls `reset()`
  (which wipes constraints first) or reaches `detach_car()` with
  constraints intact. With the clear as the first statement of
  `reset()` AND at the top of `detach_car()`, no exit can reach either
  without the person marker still present. The hunter's caller walk this
  round covered every remaining `detach_car` / `reset` caller.
- Proposed fix: make `self._clear_leaked_person_target_if_needed()` the
  **first statement** of `QSChargerGeneric.reset()`, before
  `super().reset(keep_commands=keep_commands)`. The constructor's
  `reset()` at `:2334` is safe: `self.car is None` (`:2287`) and
  `_has_live_person_constraint` returns before touching `_constraints`.
  The explicit calls at `:3711` / `:3772` become redundant — **keep them**
  (idempotent, and removing them is outside the convergence constraint).
  Add two **red-first** tests:
  `test_reset_button_with_live_person_constraint_clears_target`
  (`await charger.user_clean_and_reset()` with
  `update_charger_for_user_change` mocked → `car._next_charge_target is None`)
  and `test_disable_with_live_person_constraint_clears_target`
  (`charger.qs_enable_device = False` → `None`). Add a one-line comment in
  `reset()` mirroring the `detach_car()` one (why both sites exist).
