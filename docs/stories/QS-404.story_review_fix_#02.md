Reviewers on `51684a03`: edge-case-hunter and acceptance-auditor — no

## Fix

1. **G1 (blind-hunter) — undeclared-SVG hint by file state.** A leftover
   that `main` lacks can only be deleted (a `git checkout origin/main --`
   would fail); a path `main` holds can only be restored (deleting it is
   refused next run). The hint now names each case with its paths. Tests:
   `test_land_refuses_an_undeclared_untracked_svg` (no checkout hint),
   `test_land_refuses_an_undeclared_svg_main_holds_with_a_restore_hint`.
2. **G2 (CodeRabbit) — `render` never writes outside the doc's directory.**
   `mermaid_svg.run` refuses an `@out` that is not an `.svg` under the
   Markdown file's directory (symlinks resolved), in `render` and `--check`
   alike, before any write. This matters now that `.claude/settings.json`
   allow-lists the command for the epic agent. `land` keeps its own scope
   check (`out-of-scope` with the `../…` offender, AC 5). Every `@out` in
   `docs/` already complies. Tests:
   `test_run_refuses_an_out_outside_the_markdown_directory` (parent,
   absolute, not-svg, `.SVG.bak`; render and check),
   `test_run_refuses_an_out_through_a_symlink_leaving_the_directory`.
3. **G3 (blind-hunter) — `compile(..., dont_inherit=True)`** so `main`'s
   renderer is compiled with its own `__future__` flags, not `epic_doc`'s.
4. **G4 (acceptance-auditor) — AC 2 asserts the doc bytes too** after a
   rejected push.

## Rejected

- Extend the import-contract pin to class bodies, decorators and defaults
  (blind-hunter): those only define dataclass fields today, and the
  whole-tree `open` / `__file__` / `__spec__` scans already apply.
- A broken `main` renderer blocking an SVG-only cleanup whose local SVG is
  stale (blind-hunter): accepted by design in story D5 ("that state means a
  re-render without a doc change").
- Case-only `@out` renames against `main`'s tree (blind-hunter,
  edge-case-hunter): rare, and CI runs on a case-sensitive file system; F6
  already covers the in-document case.
- The pinned sha in the renderer's filename / refusal details
  (blind-hunter, acceptance-auditor): cosmetic; the sha is `origin/main` as
  fetched at the start of `land`.
