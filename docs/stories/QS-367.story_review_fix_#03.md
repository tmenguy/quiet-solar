## Findings to fix

### [should-fix] S1 — `test_check_cli_floor_default_is_models_constant` does not test its named property
- File: `tests/qs/launchers/test_claude_launcher.py:~1562-1571`
- Severity: should-fix
- Source: qs-review-blind-hunter, qs-review-edge-case-hunter
- Description: the test asserts `models.CLAUDE_CLI_FLOOR == (2, 1, 280)` and
  that `"0.0.1"` warns. A hard-coded default `floor=(2, 1, 280)` in
  `check_cli_floor` that no longer reads from `models` would pass, so the
  "no drift" property the test is named after is not pinned.
- Proposed fix: assert
  `inspect.signature(claude_launcher.check_cli_floor).parameters["floor"].default is models.CLAUDE_CLI_FLOOR`.
  Also derive "just below" and "at" the floor from the constant itself
  (`(M, m, p-1)` when `p > 0`, else `(M, m-1, 999)`) and assert warn / no-warn
  respectively, so the test keeps working when the floor is bumped.

### [should-fix] S2 — `proc.stdout or proc.stderr` scans one stream; docstring says both
- File: `scripts/qs/launchers/claude.py:~125` (docstring), `~:143-144`
  (call), `~:98` (regex — first triple wins)
- Severity: should-fix
- Source: qs-review-blind-hunter, qs-review-edge-case-hunter
- Description: stderr is consulted only when stdout is empty; a stdout of
  `"\n"` or a banner without a version hides a version printed on stderr.
  The docstring claims "both streams are scanned" and
  `test_build_payload_reads_stderr_version` covers only the empty-stdout
  case. Separately, the regex takes the first `X.Y.Z` anywhere, so
  `"Update available: 2.1.290\n2.1.278 (Claude Code)"` reads 2.1.290 and
  stays silent (confirmed by running it).
- Proposed fix: scan `f"{proc.stdout or ''}\n{proc.stderr or ''}"`. In
  `check_cli_floor`, prefer a triple immediately followed by
  `(Claude Code)` (e.g. `re.search(r"(?<![\d.])(\d+)\.(\d+)\.(\d+)\s*\(Claude Code\)", text)`),
  falling back to the first bare triple. Tests: stdout non-empty without a
  version + version on stderr → warns; the "Update available: 2.1.290 /
  2.1.278 (Claude Code)" banner → warns; existing rows unchanged.
