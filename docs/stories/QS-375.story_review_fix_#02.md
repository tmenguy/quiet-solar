# QS-375 — review fix #02 (PR #411, round 2)

Reviewers on `306fa176`: blind-hunter, edge-case-hunter and
acceptance-auditor. CodeRabbit is still rate-limited. The auditor confirmed
both round-1 gaps closed, every F-item implemented and tested, and no AC or
decision contradicted; one must-fix (coverage), and the hunters found a few
holes left by fix #01.

## Fix

1. **G1 (acceptance-auditor, must-fix) — `cli._sql_id`'s non-integer branch
   is untested,** so the whole-suite Control Plane coverage is 99.95%. A
   non-integer id is tested (`USAGE`).
2. **G2 (all three) — `file: "a.py:42/"` passes F4.** `norm_path`
   normalises first, then checks the result (absolute, `..`, backslash, a
   `:<line>` suffix), and also refuses a drive letter (`C:/…`).
3. **G3 (blind-hunter, edge-case-hunter) — non-UTF-8 stdin and lone
   surrogates are `INTERNAL`.** `finding open --input -` maps a
   `UnicodeDecodeError` to `USAGE`; a string field holding a lone surrogate
   (`"x\ud800"`) is `USAGE`.
4. **G4 (all three) — `blast-radius set` is not stripped.** `--head-sha`,
   `--review` and `--reason` go through `_text` (a blank required one is
   `USAGE`, a blank reason is NULL), and so does the reader's `head_sha`.
5. **G5 (blind-hunter, edge-case-hunter) — `--cause` reads any run.** Like
   `relates_to` (F2), a cause outside the writer's run is `NOT_FOUND`.
6. **G6 (blind-hunter) — a blank `--commit` on another target** is `USAGE`
   again: "given" is decided before stripping.
7. **G7 (edge-case-hunter) — `_check_ci` compares a stripped item `sha`**
   with the task's `ci_sha` stripped too.
8. **G8 (blind-hunter, edge-case-hunter) — `file` and `symbol` are NFC
   normalised,** so a composed and a decomposed spelling are one
   fingerprint.
9. **G9 (edge-case-hunter) — a blank `sha` is absent,** like every optional
   key field (so a blank `sha` on a reviewer item is no longer `USAGE`).
10. **G10 (blind-hunter, edge-case-hunter) — backticks in code spans.** The
    export drops backticks from the values it puts in code spans, and the
    blast-radius line (a paragraph, not a table) only collapses whitespace.
11. **G11 (blind-hunter, edge-case-hunter) — `show`'s flagged states** come
    from a sub-select over `json_each(flags)`, with no bind list.
12. **G12 (docs)** — `control-plane.md`: only the optional key fields and
    the CLI flags are stripped (`title` and `body` are stored as given); the
    arguments are validated before the token (so an ID-taking command's
    stale token wins over `NOT_FOUND`, not over `USAGE`); `task show`
    carries the same *ledger* keys. The story's D8 notes F15's refinement
    (NFKC + casefold).
