## Design of the strengthened test

Refactor `test_six_phases_section_has_pipeline_diagram` in
`tests/qs/docs/test_overview_structure.py` around a small pure parser
`_parse_pipeline_diagram(block: str)`. Then test the parser directly on
mutated copies of the real block with a parametrized test. Do not write
scratch files. Use string replacement on the block from
`_six_phases_section()`.

`_parse_pipeline_diagram` classifies **every non-blank line** of the block
after `strip()` and returns `nodes`, `edges` and `subgraphs`. Each line
must be exactly one of the following kinds, otherwise it raises
`AssertionError(f"unrecognised diagram line: {line!r}")`:

| kind | regex (on the stripped line) |
|---|---|
| header | `^flowchart (TB\|LR\|TD\|BT\|RL)$` (first line only) |
| node | `^(\w+)\["([^"]*)"\]$` |
| edge | `^(\w+) (-->\|-\.->)(?:\|"([^"]*)"\|)? (\w+)$` (allow `\s*` around the arrow) |
| subgraph open | `^subgraph (\w+)\["([^"]*)"\]$` |
| subgraph close | `^end$` |
| classDef | `^classDef \w+ .+$` |
| class | `^class [\w,]+ \w+$` |
| style | `^style \w+ .+$` |
| invisible link | `^\w+ ~~~ \w+$` (allowed by the Free list; not counted as an edge) |
| comment | `^%%` |

Rules:
- A node declared twice → `AssertionError` (fixes N3).
- A node line inside an open subgraph records its membership.
- Nested subgraphs are not allowed (assert).
- `edges` is `dict[(src, dst), (arrow, label)]`, with `label` set to `None`
  when there is none. A duplicate `(src, dst)` → `AssertionError`.

## Required mutation test

Add a parametrized test,
`test_pipeline_diagram_rejects_mutation[<case>]`. Each case applies one
`str.replace` to the real block, runs it through the parser and the
pinned comparisons, and expects `AssertionError` (`pytest.raises`).
Assert that each replace actually changed the block, so a stale case
cannot pass vacuously. The cases, each a minimum:
1. `fin -.->` → `fin -->` (solid "separate decision" edge)
2. `dec -->` → `dec -.->` (dashed decompose edge)

5. append the line `rel --> setup --> plan`
6. append the line `x("stray")`
7. move `ver[...]` out of the BUG subgraph: remove the line and re-add it
   after the last `end`

9. declare `setup` a second time without ✋

The positive path, the real block, must still pass
`test_six_phases_section_has_pipeline_diagram`.
