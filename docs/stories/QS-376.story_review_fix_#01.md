## Findings to fix

### [should-fix] EC1 — the reservation can make shaving impossible, so no reduction is applied
- File: `custom_components/quiet_solar/ha_model/charger.py` (`budgeting_algorithm_minimize_diffs`, "CAN'T SHAVE BUDGETS")
- Source: qs-review-edge-case-hunter
- Description: `_isolated_reserved_amps` cannot be shaved. If the reservation plus the healthy members'
  minimums is above the group max (for example, the group max drops in off-grid mode, or a forced
  consign), both shave attempts fail and the algorithm returns without reducing anyone.
- Proposed fix: reductions always win. When both attempts fail and a reservation exists, log a
  WARNING, clear the reservation for this cycle, and run `_do_prepare_and_shave_budgets` once more.
  Add a test.

### [should-fix] EC2 — the "10 min off→on spacing" after re-arm only holds for green commands
- File: `docs/agents/concepts/charger-budgeting.md` (F2 bullet), story notes
- Source: qs-review-edge-case-hunter
- Description: forced commands (`CMD_AUTO_FROM_CONSIGN` / `CMD_ON` / `CMD_AUTO_PRICE`) never offer
  0 A, so the budget restarts a re-armed charger on its next pass (~20 min rounds, not ~30 min).
- Proposed fix: correct the documented cadence in the doc and the story notes. No behaviour
  change: a forced consign is an explicit "charge now" request, and retrying it sooner is
  intended. The group is still only blocked during the ~4:30 launch window.

## Findings skipped (with reason)

- **CR1** — reserve an upper bound instead of the expected setpoint. Every normal start already
  budgets only the expected amps before the charge is confirmed. Before a stop, QS lowers the
  hardware setpoint to the idle/min charge, so the expected amps match what a late start would
  draw. A stuck OCPP charger (V-held) is faulted by F3 and leaves the group entirely. Skipped.
- **CR2 / EC3** — keep the reservation after re-arm. A start landing more than 15 min after its last
  command is not a realistic failure mode. If it happens, the next cycle sees "charging, want
  stop": the group blocks further budgeting and QS stops the charge. With a group current sensor,
  the measured-current path already covers it. Skipped.
- **EC6** — nudge rate limit reset on recovery. Clearing it on recovery is the plan's explicit
  decision: a new hold episode deserves an immediate nudge. Flapping the switch every cycle is not
  an observed mode. Skipped.
- **EC9** — a charger stuck on an earlier check (pending reboot / phase mismatch) never re-arms. This
  is still strictly better than before (the group is no longer blocked). Covered by follow-up 3
  (other non-converging members). Skipped.
