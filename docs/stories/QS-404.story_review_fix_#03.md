## Fix

1. **H1 (blind-hunter, edge-case-hunter, acceptance-auditor) — an undeclared
   SVG already equal to `main` is not refused.** `changed` is computed
   against the worktree's base, so an orphan SVG that `main` changed after
   the base stays changed even after the user follows the G1 hint
   (`git checkout origin/main -- <path>`), and `land` refused again with the
   same hint — a loop. Likewise an orphan deleted on both sides was refused
   with a "delete it" hint for a file that no longer exists. Step 8 now
   skips an undeclared SVG whose local blob equals `main`'s: it builds as a
   no-op (`_build_commit` writes `main`'s blob, or removes a path `main`
   lacks), and the post-land reset aligns the file. Tests:
   `test_land_an_undeclared_svg_equal_to_main_is_not_refused` (refused, then
   the hint followed literally with a real `git checkout`, then `landed`),
   `test_land_an_undeclared_svg_deleted_on_both_sides_is_not_refused`.
