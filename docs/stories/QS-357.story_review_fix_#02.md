## Findings to fix

### [should-fix] `render_all` lets template-load errors escape, breaking the handoff invariant
- File: `scripts/qs/render_agents.py:344`
- Severity: should-fix
- Source: qs-review-edge-case-hunter (caller side also flagged by
  qs-review-blind-hunter)
- Description: In `render_all`, `env.get_template()` (~line 344) sits
  **outside** the `try/except jinja2.TemplateError` block (the `try`
  begins at ~line 355 and wraps only `template.render`). A
  `TemplateSyntaxError` or `TemplateNotFound` raised at template *load*
  time therefore escapes `render_all` as a raw `jinja2.TemplateError` —
  which is neither `ImportError` nor `render_agents.RenderError`. The
  handoff render handler in `next_step.py` (~line 238) catches only
  `ImportError` and `RenderError`, so a load-time template error
  **propagates and breaks the handoff**. This violates the invariant
  documented at `next_step.py:203-204` ("a render failure must NEVER
  break a handoff") — the very guarantee the review-fix #01 S1 warning
  block now depends on. The gap is pre-existing (not introduced by the
  S1 commit) but the fix's degradation-warning contract rests on it.
- Proposed fix: Move the `env.get_template()` call inside the guarded
  block (or add a dedicated guard) so that `jinja2.TemplateError` raised
  at load time is caught and re-raised as `render_agents.RenderError`,
  consistent with how render-time errors are already wrapped. This keeps
  every render failure funneling through `RenderError`, which both
  `setup_task.py` (`_fail_render → exit 1`) and `next_step.py`
  (warn-and-continue) already handle correctly.
- Tests: Add a test in `tests/qs/test_render_agents.py` that points the
  renderer at a templates dir containing a template with a Jinja syntax
  error (or a missing template) and asserts `render_all` raises
  `RenderError` (not a raw `jinja2.TemplateError`). Also add/extend a
  `tests/qs/launchers/test_next_step_cli.py` case proving a load-time
  template failure at handoff produces a stderr warning and still emits
  the payload with exit 0 (the handoff-survives-render-failure
  invariant). Folding in review finding N8: prefer a test that exercises
  this via a real (reachable) failure path rather than a monkeypatched
  impossible state dict.
