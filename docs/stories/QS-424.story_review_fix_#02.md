## Findings to fix

### [must-fix] G1 — a fence inside a list item escapes the export's scanner and swallows the rest of the summary
- File: `scripts/qs/control_plane/export.py` (`_value_lines`)
- Source: blind-hunter, edge-case-hunter (verified on GitHub)
- Description: the scanner tracks fences as if every fence were top level. `"1. Run:\n   ```bash\n   make\n```\nthen done"` (a column-0 closer), or `"- item\n  ```\n  code"` (fix #01's appended column-0 closer then opens a new fence), leave a fence open over `### Questions` and `## Acceptance criteria`.
- Proposed fix: render every value as a **blockquote** (each line prefixed `> `, a blank line `>`). The blank line after the value ends the quote, which closes any fence, list or HTML block opened inside it, however nested (verified on GitHub by the edge-case hunter). Drop the end-of-value fence closer. Keep the heading demotion (now also after `>` / list-marker prefixes, keeping the prefix and indentation) and the best-effort fence tracking, whose only job left is to keep code comments as they are. Tests: the three repro values, an unclosed `<details>`, and a `> # x` / `- # x` value.

### [should-fix] G2 — Unicode whitespace is not CommonMark whitespace
- File: `scripts/qs/control_plane/export.py`
- Source: edge-case-hunter

- Proposed fix: `.strip(" \t")` in the three places; tests with `"text\n\xa0\n---"`.

## Rejected (with reasons)

- Use `--` before the prompt instead of refusing a leading `-` (blind-hunter): `--` was not checked live (the story says so and does not use it); the refusal is safe and AC9's live run can revisit it.
- Guard an empty or NULL nonce in the scrub (blind-hunter): `nodes.nonce` is `NOT NULL` and always `tokens.new_nonce()` (32 hex).
- `except A, B, C:` is invalid syntax (coderabbit): valid on Python 3.14 (PEP 758), which the package requires; the tests import the module.
- The epic amendment is out of scope (coderabbit): it is the maintainer's decision E, task 8 of the story.
- Raw `<h2>` HTML in a value (blind-hunter): raw HTML stays out of the digest's scope; now quoted, it cannot end the summary's sections.
- Over-demoting a `#` line in a mis-tracked code block: cosmetic only now that the blockquote holds the structure.
