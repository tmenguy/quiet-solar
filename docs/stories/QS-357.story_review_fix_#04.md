## Root cause (M2 / S6 / N12)

Review-fixes #02 and #03 closed the loader-*input* side of the "a render
failure must NEVER break a handoff" invariant. `_atomic_write` is the
*output* side, and its docstring already claims output `OSError` funnels
through `RenderError` — but the guarantee is not upheld: the directory
creation and temp-file creation happen **outside** the `try`, and the
`except` is too narrow. Same invariant, write side.

## Findings to fix

### [must-fix] M2 — `mkdir`/`mkstemp` outside the try escape `render_all`
- File: `scripts/qs/render_agents.py:298`
- Severity: must-fix
- Source: qs-review-edge-case-hunter
- Description: In `_atomic_write`, `path.parent.mkdir(parents=True,
  exist_ok=True)` (~line 298) and `tempfile.mkstemp(dir=str(path.parent),
  ...)` (~line 299) sit outside the `try` (which starts ~line 301). Their
  `OSError` escapes `_atomic_write` and `render_all` uncaught — it is
  never wrapped as `RenderError`. Both call sites catch only
  `(ImportError, RenderError)`, so this breaks the handoff, defeating the
  invariant the docstring claims. Reproduces when the output parent is
  unwritable or occupied by a non-dir: `.claude` exists as a file
  (`NotADirectoryError`) or the `.claude/agents` chain is read-only
  (`PermissionError`).
- Fix: move `mkdir` and `mkstemp` inside the `try` so their `OSError` is
  wrapped as `RenderError` like `os.replace` already is.

### [should-fix] S6 — `UnicodeEncodeError` on write escapes uncaught
- File: `scripts/qs/render_agents.py:302`
- Severity: should-fix
- Source: qs-review-edge-case-hunter
- Description: `_atomic_write`'s `except` catches only `OSError`, but
  `handle.write(text)` UTF-8 encoding raises `UnicodeEncodeError` (a
  `ValueError`, not `OSError`) when `text` contains lone surrogate code
  points → escapes `render_all` → breaks handoff. This is the write-side
  mirror of the decode `ValueError` the load boundary deliberately
  catches (`_load_errors` includes `ValueError`); the asymmetry is the
  gap.
- Fix: widen the `_atomic_write` `except` to `(OSError, ValueError)` (or
  `OSError, UnicodeError`) and re-raise as `RenderError`.

### [nice-to-have] N12 — `finally` unlink can mask the in-flight error
- File: `scripts/qs/render_agents.py:308`
- Severity: nice-to-have
- Source: qs-review-edge-case-hunter
- Description: `finally: tmp.unlink()` can itself raise `OSError` (temp
  vanished, or dir perms changed mid-call) and mask the original
  exception. Narrow race window.
- Fix: `tmp.unlink(missing_ok=True)` and/or wrap in
  `contextlib.suppress(OSError)`.

### [nice-to-have] N15 — assert the render-time twin independently
- File: `tests/qs/test_render_agents.py`
- Severity: nice-to-have

- Description: S4's render-time boundary (non-jinja2 loader error from an

- Fix: add a test that corrupts `_base.md.j2` (the `extends` parent) with

  raises `RenderError`, proving the render-boundary widened catch fires.

## Suggested implementation shape

M2 + S6 + N12 are one coherent `_atomic_write` edit:

```python
def _atomic_write(path, text):
    try:
        path.parent.mkdir(parents=True, exist_ok=True)
        fd, tmp_name = tempfile.mkstemp(dir=str(path.parent), ...)
        tmp = Path(tmp_name)
        with os.fdopen(fd, "w", encoding="utf-8") as handle:
            handle.write(text)
        os.replace(tmp, path)
    except (OSError, ValueError) as exc:
        raise RenderError(...) from exc
    finally:
        with contextlib.suppress(OSError):
            if tmp is not None and tmp.exists():
                tmp.unlink()
```

Add tests: `_atomic_write` (or `render_all`) raises `RenderError` when
the parent dir is unwritable / occupied by a file, and when the text
contains a lone surrogate; the N15 parent-corruption test; and confirm
the handoff path still exits 0 with a stderr warning. Keep fixtures in
`tmp_path` / `out_root` per story §7.
