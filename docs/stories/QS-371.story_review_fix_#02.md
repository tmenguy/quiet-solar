## Findings to fix

### [should-fix] R1 — S2 rule (d) checks the package dir, not `custom_components/`
- File: `scripts/qs/quality_gate.py:1766-1768` (`_path_moves_tool_verdict`)
- Source: qs-review-edge-case-hunter + qs-review-blind-hunter + qs-review-acceptance-auditor
- Description: the comment, the `check_impacted` docstring and the PR body all say "repo root or anywhere under `custom_components/`". The code actually tests `p.startswith(_CHEAP_PACKAGE_PREFIX)`, which is `custom_components/quiet_solar/`. `custom_components/ruff.toml`, `custom_components/.ruff.toml` and `custom_components/pyproject.toml` all return False. Ruff picks the closest config walking up the tree, so any of these would change CI's verdict.
- Proposed fix:
  - In rule (d), test `p.startswith("custom_components/")`. Add a module constant `_CHEAP_COMPONENTS_PREFIX = "custom_components/"` for it.
  - Extend (b) to `p in {"custom_components/__init__.py", "custom_components/__init__.pyi"}`.
  - Add `test_trigger_table` rows for `custom_components/ruff.toml`, `custom_components/pyproject.toml`, `custom_components/__init__.pyi`, root `ruff.toml` and root `.mypy.ini`, all mapping to TOOLS.
  - Rename the id `ruff-toml-root`, which covers `.ruff.toml`, to `dot-ruff-toml-root`.
  - Keep the negative `docs/ruff.toml` row.

### [should-fix] R2 — The full-gate text output hides stderr whenever detail is set
- File: `scripts/qs/quality_gate.py:1234-1240` (`_output_results`)
- Source: qs-review-edge-case-hunter + qs-review-blind-hunter
- Description: `reason = r.get("detail") or r.get("stderr")` only shows stderr when detail is empty. The S3 generator-failure detail says "see stderr below", and then no stderr follows. The same happens for ruff/mypy when both stdout and stderr are non-empty.
- Proposed fix: on failure, print the detail lines (first 5), then the stderr lines (first 5), and skip whichever is empty. This mirrors `_impacted_cheap_checks`. Keep the stderr-only test. Add a test where both fields are set, asserting that both lines appear and detail comes before stderr.
